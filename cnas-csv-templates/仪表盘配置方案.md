# CNAS体系多维表 - 仪表盘配置方案

## 1. 钉钉多维表仪表盘功能说明

钉钉多维表支持「仪表盘」视图，可基于数据表自动生成统计图表，支持：
- 数字卡片（汇总统计）
- 柱状图/条形图（分类统计）
- 饼图/环形图（占比统计）
- 折线图（趋势统计）
- 透视表（交叉分析）

每个数据表可以创建多个仪表盘视图，面向不同角色展示不同指标。

### 3.2 图表详细配置

| 配置项 | 值 |
|--------|-----|
| 数据表 | 人员资质管理 |
| 统计方式 | 计数 |
| 筛选条件 | 人员状态 = 在职 |
| 显示格式 | 数字 + "人" |

#### 图表2：在用设备数（数字卡片）

| 配置项 | 值 |
|--------|-----|
| 数据表 | 设备生命周期管理 |
| 统计方式 | 计数 |
| 筛选条件 | 设备状态 = 在用 |
| 显示格式 | 数字 + "台" |

#### 图表3：年度质控完成率（数字卡片）

| 配置项 | 值 |
|--------|-----|
| 数据表 | 质量控制计划 |
| 统计方式 | 百分比 |
| 计算公式 | 已完成数 / 总数 * 100% |
| 筛选条件 | 审核年度 = 当前年度 |
| 显示格式 | 百分比 |

#### 图表4：不符合项闭环率（数字卡片）

| 配置项 | 值 |
|--------|-----|
| 数据表 | 不符合/纠正措施 |
| 统计方式 | 百分比 |
| 计算公式 | 已关闭数 / 总数 * 100% |
| 显示格式 | 百分比 |

#### 图表5：人员授权状态分布（环形图）

| 配置项 | 值 |
|--------|-----|
| 数据表 | 资质授权（子表） |
| 分组字段 | 授权状态 |
| 统计方式 | 计数 |
| 显示标签 | 类别名 + 数量 + 百分比 |

#### 图表6：设备状态分布（环形图）

| 配置项 | 值 |
|--------|-----|
| 数据表 | 设备生命周期管理 |
| 分组字段 | 设备状态 |
| 统计方式 | 计数 |
| 颜色方案 | 在用=绿色、停用=灰色、维修中=橙色、外出=蓝色、报废=红色 |

| 配置项 | 值 |

| 数据表 | 不符合/纠正措施 |

| 颜色方案 | 已关闭=绿色、其他=红色 |

#### 图表8：月度检测项目趋势（折线图）

| 配置项 | 值 |
|--------|-----|

|--------|-----|

## 8. 钉钉中创建仪表盘的操作步骤

### 步骤1：打开数据表

1. 在多维表空间中，点击目标数据表
2. 点击顶部「+视图」按钮
3. 选择「仪表盘」视图类型

### 步骤2：添加图表组件

1. 点击「添加图表」
2. 选择图表类型（数字卡片/柱状图/饼图/折线图/透视表/列表）
3. 配置数据源：
   - 选择统计字段
   - 设置分组方式
   - 添加筛选条件
4. 调整图表样式（颜色、标签、标题）

### 步骤3：调整布局

1. 拖拽图表调整位置
2. 拖拽边框调整大小
3. 建议每个仪表盘4-10个图表，避免信息过载

### 步骤4：命名并保存

1. 点击视图名称，输入仪表盘名称（如"质量负责人驾驶舱"）
2. 仪表盘配置自动保存

### 注意事项

- 钉钉多维表的仪表盘**只能基于单张数据表**创建
- 跨表汇总的仪表盘需要在每张表上分别创建图表，无法在一个视图中跨表联动
- 如需跨表综合视图，建议使用「看板视图」配合筛选条件实现
