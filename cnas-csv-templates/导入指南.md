## 2. 导入步骤（按顺序执行）

### 第一步：先导入基础数据配置表

> 基础配置数据是其他表的选项来源，必须先导入

1. 在多维表空间中，点击「新建数据表」->「从CSV导入」
2. 选择 `07_基础数据配置.csv`
3. 导入后，手动调整字段类型：
   - 配置项 -> 单选
   - 选项值 -> 单行文本
   - 排序 -> 数字
   - 备注 -> 多行文本

### 第二步：导入6张主表（按以下顺序）

**顺序很重要**，因为存在关联依赖：

1. **05_文件控制管理.csv** -> 文件控制管理表
2. **01_人员资质管理.csv** -> 人员资质管理表
3. **02_设备生命周期管理.csv** -> 设备生命周期管理表
4. **04_检测业务管理.csv** -> 检测业务管理表
5. **06_不符合纠正措施.csv** -> 不符合/纠正措施表
6. **03_1_质量控制计划.csv** / **03_2_内部审核.csv** / **03_3_管理评审.csv** -> 质量活动管理表（3个子表合并或分别导入）

### 第三步：导入子表

每张主表导入后，添加对应的子表：

| 主表 | 子表CSV |
|------|---------|
| 人员资质管理 | 01_1_资质授权.csv, 01_2_培训记录.csv, 01_3_监督记录.csv |
| 设备生命周期管理 | 02_1_校准记录.csv, 02_2_期间核查记录.csv, 02_3_维护记录.csv |
| 检测业务管理 | 04_1_检测方法.csv, 04_2_样品记录.csv, 04_3_报告记录.csv |
| 文件控制管理 | 05_1_修订历史.csv |

## 3. 字段类型配置

导入CSV后，钉钉默认所有字段为文本类型，需要手动调整为正确类型：

### 3.1 通用字段类型对照

| CSV中字段特征 | 应设置为 | 说明 |
|---------------|----------|------|
| 日期格式(YYYY-MM-DD) | 日期 | 如入职日期、校准日期等 |
| 包含"|"分隔的多值 | 多选 | 如受审核部门、检测领域 |
| 固定几个取值 | 单选 | 如设备状态、闭环状态、文件层级 |
| 数字+单位 | 数字 | 如校准费用、培训时长 |
| 邮箱格式 | 邮箱 | 如联系邮箱 |
| 电话号码 | 电话 | 如联系电话 |
| 长文本描述 | 多行文本 | 如不符合描述、备注 |
| URL格式 | 超链接 | 如文件链接、SOP链接 |
| 人名 | 人员 | 如责任人、审核人 |

## 4. 表间关联配置

导入所有表后，需要配置表间关联关系：

| 源表 | 添加关联字段 | 关联到 | 关联类型 |
|------|------------|--------|----------|
| 人员资质管理 | 授权检测领域 | 检测能力范围(基础配置) | 多选 |
| 人员资质管理 | 授权设备 | 设备生命周期管理 | 多选 |
| 检测业务管理 | 检测人员 | 人员资质管理 | 多选 |
| 检测业务管理 | 复核人员 | 人员资质管理 | 多选 |
| 检测业务管理 | 使用设备 | 设备生命周期管理 | 多选 |
| 不符合/纠正措施 | 来源活动-内审 | 内部审核 | 单选 |
| 不符合/纠正措施 | 来源活动-管评 | 管理评审 | 单选 |
| 不符合/纠正措施 | 来源活动-质控 | 质量控制计划 | 单选 |

**配置方法：**
1. 打开目标表 -> 点击「+」添加字段
2. 选择「关联」类型
3. 选择关联的目标表
4. 设置关联类型（一对多/多对多）

## 6. 预警自动化配置

在钉钉多维表中配置自动化规则：

### 6.1 人员授权到期预警

```
触发条件：每天 09:00
筛选条件：资质授权表.有效期至 - 今天 <= 30 且 授权状态 = 有效
执行动作：发送钉钉消息给 人事专员
消息内容："[预警] 以下人员授权即将到期，请及时安排续期：{人员姓名} - {授权名称} - 到期日期：{有效期至}"
```

### 6.2 设备校准到期预警

```
触发条件：每天 09:00
筛选条件：校准记录表.下次校准日期 - 今天 <= 30
执行动作：发送钉钉消息给 设备管理员
消息内容："[预警] 以下设备校准即将到期：{设备编号} {设备名称} - 下次校准日期：{下次校准日期}"
```

### 6.3 不符合项超期预警

```
触发条件：每天 09:00
筛选条件：不符合纠正措施表.计划完成日期 < 今天 且 闭环状态 ≠ 已关闭
执行动作：发送钉钉消息给 责任人
消息内容："[预警] 不符合项已超期，请尽快处理：{不符合项编号} - {不符合描述} - 计划完成日期：{计划完成日期}"
```

### 6.4 文件评审到期预警

```
触发条件：每周一 09:00
筛选条件：文件控制管理表.下次评审日期 - 今天 <= 30
执行动作：发送钉钉消息给 文件管理员
消息内容："[预警] 以下文件即将到评审日期：{文件编号} {文件名称} - 下次评审日期：{下次评审日期}"
```

## 7. 注意事项

### 7.1 导入顺序

务必按照 第一步 -> 第二步 -> 第三步 的顺序导入，避免关联字段无法匹配。

### 7.2 编码问题

如果导入后中文显示乱码，请用文本编辑器将CSV文件转为UTF-8编码后重新导入。

### 7.3 子表处理

钉钉多维表支持子表（关联记录），导入子表CSV后需要：
1. 在主表中添加「关联记录」字段
2. 设置关联到对应的子表
3. 手动关联已有记录

### 7.4 示例数据

CSV中包含的示例数据（E001-E006、EQ-0001-EQ-0008等）仅供演示字段用法，导入后可根据实际情况修改或删除。

### 7.5 历史模板字段

每张业务表如需保留历史模板引用，可额外添加以下字段：
- 历史模板V1.0（超链接）
- 历史模板V1.1（超链接）
- 历史模板V2.0（超链接）
- 历史备注（多行文本）
